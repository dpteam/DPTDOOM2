# Источники в `refs/`

`refs/` — локальная папка, целиком в `.gitignore`. Здесь перечислено, что в ней
лежит и для чего. **Наличие кода в `refs/` не означает, что его можно включить в
проект**: сначала проверяются лицензия и происхождение.

| Папка | Что это | Для чего |
|---|---|---|
| `DPTDOOM-C` | Первый DPT.DOOM на C/DoomGeneric | идеи, документация, лаунчер, master, тесты |
| `csDoomNew`, `csDoomOld07` | csDoom (клиент/сервер, QuakeWorld-подобная сеть) | идеи по сетевому коду |
| `csDoomMaster` | старый мастер-сервер | сверка протокола списка серверов |
| `doom_ace-master` | DOOM ACE | идеи по DECORATE-подобным расширениям |
| `dukenukem3d-master` | Duke Nukem 3D (GPL v2) | идеи UX/фич BUILD-движка |
| `prboom-plus` | PrBoom+ | сверка Boom/MBF поведения |
| `ANOM_Style` | стиль интерфейса владельца | только палитра и типографика лаунчера |
| `iwads` | лицензионные IWAD владельца | локальные тесты, в Git не попадают |
| `NATUPNPLib` | обёртка UPnP | возможная будущая поддержка проброса порта |
| `Fly` | FlyWire-коннектом дрозофилы на C# (139k нейронов, 3.7M синапсов, LIF-симуляция) | образец «маленького мозга» для ботов, см. ниже |

## `refs/Fly`: откуда взялась идея мозга ботов

Это не библиотека для переноса, а **образец архитектуры**. Внутри:

| Файл | Что делает |
|---|---|
| `NeuroFlyEngine/RawConnectomeLoader.cs` | читает `classification.csv.gz` и `connections_princeton.csv.gz` (FlyWire) |
| `NeuroFlyEngine/LIFSim.cs` | симуляция «утечных» нейронов: заряд, порог, рефрактерность, задержка торможения |
| `NeuroFlyEngine/SignalBuilder.cs` | превращает частоты популяций в поведение |
| `FlyPet/World.cs` | как сигналы двигают существо по столу |

Главное, что оттуда взято: **поведение = сравнение частот нескольких
популяций**, а не глубокие сети.

- `RateDNaL - RateDNaR` → `TurnBias` (поворот);
- `RateFwd` → `WalkDrive` (идти вперёд);
- спайк гигантского волокна (`ConsumeGF`) → `Escape`;
- `RateMDN` → `Backward`;
- `RatePop` → `Arousal`.

Это десяток чисел на тик — то, что живёт на слабом железе. Тот же приём
использован в `src/Doom/World/BotBrain.cs`: у каждого стиля игры накопленный
счёт, как частота популяции, и бот сравнивает счета вместо того, чтобы держать
жёсткое правило. Подробности — в `docs/BOTS.md`.

Сам коннектом (`.csv.gz`, ~2.5 МБ) и `FlyPet3D.exe` в поставку не входят: они
нужны были только чтобы понять принцип.

`docs/ROADMAP.md` раздел 9.

## Правила

- Не коммитить содержимое `refs/`, IWAD, сохранения, логи и личные пути.
- Не переносить код, не проверив лицензию: GPL-совместимость нужна, но её
  недостаточно — важен источник и версия.
- Для идей (алгоритмы, UX, структура) код не нужен: переносится идея, а не текст.
