# План и текущее состояние

Отметки: `[x]` — сделано и проверено, `[ ]` — не сделано.
Идеи перенесены из первого DPT.DOOM (C/DoomGeneric) и расширены.

## 1. Платформа и сборка

- [x] Порт Managed Doom (C#-перевод Linux Doom) в `DPTDOOM/`.
- [x] Целевая платформа **.NET Framework 4.0** (`net40`), `net9.0` только для тестов.
- [x] Полностью standalone: удалены Silk.NET, TrippyGL, DrippyAL, MeltySynth,
      GLFW, OpenAL Soft вместе с их лицензиями.
- [x] Свой Win32-бэкенд: `user32` + `gdi32` для окна и кадра.
- [x] Свой звук: `winmm` `waveOut` + программный микшер.
- [x] Своя музыка: MUS → MIDI через системный синтезатор.
- [x] Свой ввод: сообщения окна, без сторонних библиотек.
- [x] `src/Common/Compat.cs` — шимы для API, которых нет в net40.
- [x] Проверка `tools/check-standalone.ps1`: нет NuGet в поставляемых проектах,
      нет лишних DLL рядом с exe, цель действительно `net40`.
- [ ] **Реальный запуск на Windows XP** — код и API подобраны под XP, но
      проверки на живой машине не было.
- [ ] Кроссплатформенные бэкенды (SDL/X11) на тех же интерфейсах.

## 2. Движок

- [x] Программный рендерер: BSP, стены, полы/потолки, спрайты, свет, небо,
      fuzz, палитровые эффекты, интерполяция кадров.
- [x] Геймплей: физика, монстры, двери/лифты, оружие, секреты.
- [x] Сохранения и загрузка (ванильный DSG).
- [x] Демо: проигрывание, `-timedemo`, запись `-record`.
- [x] DeHackEd (подмножество Managed Doom).
- [x] Automap, интермиссия, финалы, титры.
- [x] Демо-совместимость: хеши мира совпадают с эталонами (тесты).

### Плавность и тайминг

- [x] Исправлен порядок кадра: дробь интерполяции и флаг обновления считаются
      вместе (`FramePacer`). До этого кадры шли `1.000 → 0.500`, и картинка
      дёргалась каждый тик.
- [x] Вывод кадра через DIB-секцию + `BitBlt` вместо медленного `StretchDIBits`.
- [x] Клиентская область окна приводится к размеру кадра.
- [x] `FrameClock`: абсолютный дедлайн вместо `Sleep` остатка.
- [x] `-fpslog`: построчный лог интервала, рендера, вывода, ожидания.

## 8. Боты

- [x] Бот строит маршрут по nav-mesh из точек внутри секторов (см. `docs/BOTS.md`).
- [x] Бот обходит всю карту MAP01 (100% секторов) и воюет по дороге.
- [x] Бот больше не ходит кругами: цель фиксируется на переход.
- [x] **Локальный кооп с ботами**: `-coopbots 3` — ты и три бота в одном мире.
- [x] Бот вместо игрока: `-bots`.
- [x] Стрельба с прицеливанием, проверка линии видимости и наличия патронов.
- [x] Выбор оружия под имеющиеся патроны.
- [x] Поиск выхода и движение к нему.
- [x] **Бот проходит уровень**: нажимает переключатель выхода (MAP01 за 0:51–0:58).
- [x] Меш держится стенными точками: покрытие 59 из 59 секторов MAP01,
      813 точек, 7638 связей.
- [x] Рёбра порталов направленные: спрыгнуть вниз можно, залезть обратно — нет.
- [x] Проверка «не пересекает ли путь стену» вместо ненадёжного
      `PointInSubsector` (пустота за стеной принадлежит тому же сектору).
- [x] Use подаётся импульсами: движок считает удержание одним нажатием.
- [x] **Бот не кружит**: движение «вперёд + вбок» без остановки на разворот
      (простой 60% → 33%, назад 0 тиков). Тест `BotMovementTest`.
- [x] Застревание лечится штрафом точки маршрута, а не отходом назад.
- [x] Монстр на пути: бот разворачивается и стреляет, а не толкается в него.
- [x] Все четыре стиля проходят MAP01: Rush 0:29, Sweeper 0:33, Cautious 0:42,
      Hunter 0:56 (headless, skill 3).
- [x] **Исправлен знаковый сдвиг угла**: `Angle.Data` — `uint`, `>>` на нём
      логический, поэтому малая поправка читалась как огромная в обратную
      сторону. Это и было причиной «постоянного угла» и вращения по кругу.
- [x] Движение отдельно от прицела: бот идёт и стреляет одновременно
      (простой 78–89% → 7–14%).
- [x] Сглаживание маршрута по видимости: не останавливаться на каждой точке.
- [x] `-botdump` + `tools/render-bot-trace.ps1`: JSON с траекторией и PNG-карта
      с путём, направлением взгляда и найденными кругами.
- [x] `-botstyle 0..3`: фиксированный стиль для сравнения и разбора трасс.
- [x] **Характер бота** (`BotTemperament`): пять осей из зерна — жадность,
      осторожность, злость, любопытство, терпение. Два бота в коопе играют
      по-разному, характер устойчив между запусками.
- [x] **Бот видит предметы** (`BotItemValue`): вид по имени спрайта, ценность в
      единицах пути, ключи бесценны, пауза после одного похода за лутом.
- [x] **Память боли** (`BotDanger`): где бот терял здоровье — там дороже идти;
      затухает, хранится в файле мозга.
- [x] Оружие под дистанцию: ракетница не стреляет в упор.
- [ ] Боевой стрейф вокруг монстра: реализован, измерен, выключен — на этой карте
      медленнее, чем стрельба на ходу (см. `docs/BOTS.md`).
- [x] Бот встаёт после смерти (жмёт Use на экране смерти).
- [x] Выход-проход (W1) засчитывается как завершение, не только переключатель.
- [x] **Мозг ботов** (`BotBrain`): четыре стиля, обучение по своим прогонам,
      запоминание маршрута и лучшего времени, файл `bots/*.brain`.
- [x] Сверка скорости: лучший результат на карту, отчёт в консоли и оверлее.
- [x] Прогон не засчитывается, если уровень закончил другой игрок.
- [x] Детерминизм: одинаковый ввод даёт одинаковый мир (тест).
- [ ] Sweeper и Hunter: на MAP01 проходят, но на картах с односторонними
      сбросами могут попасть в область, откуда граф не выводит.
- [ ] Обработка лифтов и платформ (ждать, а не толкаться).
- [ ] Ключи: если выход заперт — идти за ключом.
- [ ] Учёт монстров как препятствий и как угрозы (вес рёбер).
- [ ] Сетевые боты: хост отправляет `TicCmd` бота по сети.
- [ ] DM-боты и COOP-боты, способные проходить игру (долгосрочно).

## Идеи из первого DPT.DOOM

Перенесено из `refs/DPTDOOM-C/docs/IDEAS.md`; часть уже реализована.

- [x] Сохранение момента во время attract-демо (F2), загрузка как одиночная игра.
- [x] Headless для автоматических тестов.
- [x] Master server и лаунчер с браузером серверов.
- [x] Прямой кооператив (direct TCP lockstep).
- [ ] P2P-загрузка ресурсов: только PWAD и PK3, без коммерческих IWAD.
      Allowlist по хешам для Freedoom 1/2 и shareware DOOM1.WAD.
- [ ] In-game консоль с командами (`give`, `summon`); в МП — только с правами
      и согласованным выполнением, не локальные читы, ломающие lockstep.
- [ ] Startup-экран статуса штатным шрифтом Doom (WAITING FOR PLAYER и т.п.) —
      сделано для сети, не для всех состояний.
- [ ] Сервер с configurable max, DM- и COOP-боты, проходящие игру.
- [ ] Общий и командный чат, цветные ники, cosmetic skins.
- [ ] Сохранение онлайн-снимка игры с предупреждением об отключении от сервера.
- [ ] Hairpin NAT: manual IPv4 / DNS / opt-in HTTPS API для публичного адреса.
- [ ] Duke Nukem 3D как источник идей: прицел, auto-run, инверсия мыши.
- [ ] Публикация артефактов сборки в GitHub Actions для тестировщиков.

## Известные ограничения

- Windows XP не проверен на живой машине.
- Сеть не Internet-ready: нет шифрования, NAT traversal, аккаунтов.
- Бот пока не проходит карты до конца.
- Relay и P2P-загрузка ресурсов не реализованы.
