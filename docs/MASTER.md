# Master server

`dptdoom-master.exe` — нативный сервер списка сессий (directory). Он **не**
игровой сервер: не держит мир, не передаёт пакеты игры, не проксирует трафик.
Задача одна — чтобы игрок увидел, кто ждёт напарника.

Написан на C# под .NET Framework 4.0, без внешних зависимостей.

## Запуск

```powershell
# безопасный дефолт: только loopback
.\DPTDOOM.Master\bin\Release\net40\dptdoom-master.exe

# LAN/Internet
dptdoom-master.exe --bind 0.0.0.0 --port 25135
```

Параметры: `--config <file>`, `--bind <ipv4>`, `--port <1..65535>`,
`--lease-seconds <3..300>`, `--log <file>`, `--version`, `--help`.
CLI перекрывает конфиг.

По умолчанию слушает `127.0.0.1:25135`, lease 60 с. Это безопасный дефолт, а не
ошибка: для внешнего доступа нужен `--bind 0.0.0.0` или `bind=` в конфиге.

**Если master не отвечает снаружи — проверять надо три вещи, по порядку:**

1. **Bind.** С дефолтным `127.0.0.1` master виден только на своей машине.
   Признак: `netstat -ano | Select-String ':25135'` показывает
   `127.0.0.1:25135`, а не `0.0.0.0:25135`.
2. **Файрвол.** Правило на порт 25135:
   `powershell -NoProfile -File tools/firewall.ps1 -IncludeMaster`
   (от администратора).
3. **Проброс порта** на роутере, если master за NAT: внешний 25135 → внутренний
   25135, TCP. Подробности — `docs/NETWORK.md`, раздел «Проброс портов».

Проверка снаружи, с другой машины:

```powershell
Test-NetConnection -ComputerName play.dartpower.xyz -Port 25135
```

`TcpTestSucceeded: False` при живом процессе означает, что дело в одном из трёх
пунктов выше, а не в самом master.

## Конфиг

```text
bind=0.0.0.0
port=25135
lease-seconds=60
banlist=bans.txt
allowlist=allow.txt
access-mode=open
log=dptdoom-master.log
max-clients=24
```

`access-mode=allowlist` включается **только явно**; наличие файла allowlist само
по себе режим не включает. Пустой allowlist при включённом режиме — отказ
стартовать, а не тихое «пускаем всех».

## Списки правил

```text
# один адрес
203.0.113.7

# подсеть
192.168.10.0/24

# временный бан (UTC, обязательный Z)
203.0.113.7 until 2026-12-31T23:59:59Z

# область действия (по умолчанию both)
198.51.100.0/24 scope control
```

Правила матчатся **только по TCP source**, не по advertised-адресу: иначе бан
обходится сменой объявленного IP и задевает невиновного третьего.
Бан сильнее allowlist. Просроченные правила не действуют.

## Протокол

Directory v1, одно ограниченное TCP-соединение на запрос. Заголовок 16 байт:

```
"DPTM" | version u16 | op u16 | body length u32 | status u16 | reserved u16
```

| Op | Имя | Тело | Ответ |
|---|---|---|---|
| 1 | LIST | — | count u32 + записи по 160 байт |
| 2 | REGISTER | info 132 байта | lease 48 байт |
| 3 | HEARTBEAT | auth 40 байт | 4 байта (lease) |
| 4 | REMOVE | auth 40 байт | 4 байта |
| 5 | RELAY_HOST | — | пока не реализовано |
| 6 | RELAY_JOIN | — | пока не реализовано |

Статусы: 0 OK, 1 BAD_REQUEST, 2 UNAUTHORIZED, 3 CONFLICT, 4 CAPACITY,
5 REDIRECT.

Запись сессии (132 байта):

```
0..63    имя сессии, ASCII, null-padded
64..83   отпечаток сборки
84..103  digest ресурсов (набор WAD)
104..115 резерв, нули
116..123 текст карты: "MAP01" или "E1M1"
124..125 игровой порт
126      сложность 1..5
127      биты правил
128      версия игрового протокола
129..131 резерв, нули
```

Регистрация выдаёт `lease`: 16 байт id + 24 байта токена. Токен привязан к
исходному IP, поэтому перехваченный lease с другого адреса не продлит запись.

## Ограничения

- 128 записей, 4 на один IP.
- Тело ответа LIST ≤ `4 + 160×128`.
- Rate limit: 60 запросов за 10 с с одного IP.
- Дедлайн на соединение 3 с.
- Регистрация без аутентификации: любой может объявить сессию, поэтому
  лаунчер помечает строки как **UNVERIFIED**.

Relay (прямое соединение через master, когда NAT не пускает) объявлен в
протоколе, но **не реализован** в этой версии: операции 5/6 отвечают
BAD_REQUEST. Не считать это работающей функцией.

## Проверка

```powershell
dptdoom-master.exe --port 25140 --log master.log
powershell -NoProfile -File tools\test-master.ps1 -Port 25140
```

Скрипт говорит на протоколе напрямую: регистрирует сессию, читает список,
продлевает lease, удаляет запись и проверяет, что она исчезла. Он работает и
против оригинального C-мастера.
